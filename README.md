# Sowmiya Thangadurai - MERN Developer Portfolio

A developer-focused portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Live Website
- https://sowmi1010.github.io/my-portfolio/

## Highlights
- MERN-first project storytelling with featured full-stack work
- Skills section organized around MERN core technologies
- Experience timeline with product development + technical training background
- Responsive design with dark mode support
- Interactive sections powered by Framer Motion

## Tech Stack
- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Local Development
```bash
git clone https://github.com/sowmi1010/portfolio.git
cd portfolio
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
